# Malé Bistro Kafé — návrhy webu

Rozcestník tří vizuálních konceptů webu pro **Malé Bistro Kafé** (Krnov).

**Živě:** https://snofokles.github.io/malebistro-navrhy/

## Varianty

| | Název | Obsah |
|---|---|---|
| **V1** | Nocturne | Živá verze na Vercelu — [male-bistro-cafe.vercel.app](https://male-bistro-cafe.vercel.app) |
| **V2** | Nocturne & Gilded | Statický návrh — `v2/desktop.html`, `v2/mobil.html` |
| **V3** | Expérience Pâtisserie (Nocturne & Nectar) | Statický návrh — `v3/desktop.html`, `v3/mobil.html` |

## Struktura

```
index.html      rozcestník
v2/, v3/        desktop + mobilní HTML návrhy (Google Stitch export, 1:1)
assets/         logo + náhledové miniatury
```

Návrhy V2/V3 jsou samostatná statická HTML (Tailwind + fonty + obrázky z CDN), beze změn oproti originálnímu exportu.
